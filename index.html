🎯 실제 제작 예시 (A-EX 레시피, 작업량 8500)

오프너 : 확신 → 공경 → 교묘한 손놀림 (작업량 우선 확보)

  • ✔ 안정 상태 → 강행작업 (성공시 작업량 대폭)
  • ✔ 고품질 상태 → 집중가공 (스택 + 품질)
  • ✔ 고효율 → 교묘한 손놀림 리필 (내구 관리)
  • ✔ 견고 → 절약가공 or 밑가공 (내구 가르기)
  • ✔ 마무리 : 혁신 → 장족의 발전 → 비레고 (CP 약 80 남겨야 함)
※ 시트 예시 참고: 품질 17332/20300, 내구 45/80 상황에서 마무리 진입 성공
💡 내구 가르기 개념

견고 상태에서 절약가공(내구 5 소모) → 내구도를 0 또는 5로 끝나지 않게 자르면 마지막 공정 하나를 더 진행 할 수 있음.
예: 내구 12 → 7 → 2 (중간에 교손으로 회복 가능)

강행작업(효율500) → 0 작업량
모범작업(효율180) → 0 작업량
작업(효율120) → 0 작업량
절약작업(효율180) → 0 (내구 5 소모)
※ 기본 작업량 공식 = (작업숙련도 × 0.08 × 효율) + 2 (반올림). 게임 내 실제와 약간 차이 있지만 참고용.
