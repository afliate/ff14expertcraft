# craftlog — 영상에서 제작 기록 뽑기

게임 화면을 녹화한 영상에서 **제작 창을 읽어** 공정(턴)마다 상태(보통/고품질/…)와 수치를 CSV 로 만드는 도구예요.
영상을 줄여서 올릴 필요 없이 **원본 영상을 자기 PC 에서 그대로** 돌리면 돼요.

## 준비
```
pip install opencv-python numpy pytesseract
```
`--numbers`(작업량/품질/내구도 읽기)를 쓸 때만 [Tesseract OCR](https://github.com/UB-Mannheim/tesseract/wiki) 프로그램이 필요해요(영어 팩이면 충분). 상태만 읽을 땐 필요 없어요(공정 번호 읽기에는 필요하니 설치해 두는 게 좋아요).

## 사용
```
python extract.py 영상.mp4 --out 기록.csv --fps 1
python extract.py 영상.mp4 --out 기록.csv --fps 1 --numbers
python extract.py 영상.mp4 --out 기록.csv --roi 150,10,316,260     # 제작 창 위치/크기가 다를 때
python extract.py 영상.mp4 --out 기록.csv --dump-unknown unknown/   # 못 읽은 상태 아이콘 그림 저장
```
- `--fps 1` 이면 1초에 1프레임만 읽어요. 보통 한 공정이 3초쯤이라 충분해요(영상 20분 ≈ 2분).
- 결과 CSV: `제작(몇 번째 제작인지), 공정, 상태, 상태(영문), 표본수, 시작(초), 내구도, 작업량, 품질`.
- 공정 번호가 이어지는 구간을 한 번의 제작으로 묶어요. 공정마다 여러 프레임을 다수결로 읽어서 오타를 줄여요.

## 알려진 한계
- 제작 창이 **화면 왼쪽 위**(1280x620 기준)라고 가정해요. UI 크기/위치가 다르면 `--roi`로 창 전체(x,y,w,h)를 알려 주세요.
- 상태 아이콘 종류: 보통·고품질·최고품질·안정·견고·고효율·빠른 진행·장기 지속·완강은 읽을 수 있어요.
  **길조·최악(그림이 아직 없음)**은 `?` 로 나와요. `--dump-unknown` 으로 저장된 그림을 보고
  `cond_templates.npz` 에 이름과 함께 추가하면 돼요(필요하면 추가 스크립트를 만들어 드릴게요).
- 공정 번호를 가끔 못 읽어서 몇 공정이 빠질 수 있어요(상태 비율을 재는 데는 영향이 작아요).
- 스킬 이름은 읽지 않아요. 수치가 바뀐 모양으로 어떤 스킬이었는지 맞추는 건 별도 단계예요.
- 레시피 이름은 못 읽어요(한국어 OCR 없음). 그래서 어느 레시피 기록인지는 사람이 붙여 줘야 해요.
